Bits [27:26] = 0b00 identify the Data Processing instruction class. Other values select Load/Store, Branch, Coprocessor, etc.

TST / TEQ / CMP / CMN (codes 1000–1011): S-bit is always 1; bits [15:12] (Rd) must be 0000. Exception: Rd=R15 + S=1 triggers exception return (SUBS PC, LR).
MOV / MVN: Rn field [19:16] must be 0000 (ignored by hardware, but required for correct disassembly).
▪ S [20] · Rn [19:16] · Rd [15:12] 6 bits
FieldBitsDescription
S[20] 0 — NZCV flags unchanged
1 — NZCV updated from result
If Rd=R15 and S=1: CPSR ← SPSR (exception return mode)
Rn[19:16] First source register (R0–R15).
Ignored by MOV/MVN; must be 0000 in those encodings.
R15 (PC) reads as (instruction_address + 8).
Rd[15:12] Destination register (R0–R15).
TST/TEQ/CMP/CMN: must be 0000 (result discarded).
Writing R15 (PC): acts as branch; with S=1 also restores CPSR from SPSR.
NZCV flag semantics:
N — Negative: bit 31 of result
Z — Zero: result == 0
C — Carry: carry-out of bit 31; for SUB/CMP borrow = ¬C
V — oVerflow: signed overflow

Shift-by-register constraints: Rs ≠ R15, Rm ≠ R15, Rd ≠ R15, Rn ≠ R15. Bit[7] must be 0 — if bit[7]=1 and bit[4]=1, the encoding is decoded as a Multiply or extension instruction, not Data Processing. RRX is not available in shift-by-register mode (no register-driven RRX encoding exists).
Case I=1 → Immediate value (8-bit rotated constant)
rot_imm [11:8]

4 bits (rotate)

Formula: immediate = ROR(imm8, rot_imm × 2)
The 8-bit value is right-rotated by an even number of positions (0, 2, 4, … 30). This covers any 8-bit pattern aligned to an even bit boundary within 32 bits.

Un-encodable immediates: Any 32-bit value that cannot be expressed as an 8-bit byte rotated by an even amount cannot fit in a single instruction. The assembler must use MOVW/MOVT (ARMv6T2+) or a MOV + ORR sequence for arbitrary 32-bit constants.
Check algorithm: for each rot ∈ {0..15}, test whether ROR(value, rot × 2) fits in [0..255]. Accept the first match; reject if none found.
C-flag from immediate shifter: If rot_imm = 0 the carry-out of the shifter equals the incoming C flag (CPSR.C). If rot_imm ≠ 0, carry-out = bit 31 of the rotated value. Affects S=1 results for logical ops (AND, EOR, ORR, BIC, MOV, MVN, TST, TEQ).
Decode & Execute Pseudocode
// ─── Decode Operand2 ────────────────────────────────────────────────── function DecodeOperand2(I, op2[11:0], C_in) → (value, C_out): if I == 1: // immediate rot = op2[11:8] * 2 imm8 = op2[7:0] value = ROR32(imm8, rot) C_out = (rot == 0) ? C_in : value[31] return (value, C_out) else: // register operand Rm = Reg(op2[3:0]) stype = op2[6:5] if op2[4] == 0: // shift by immediate imm5 = op2[11:7] return ShiftImm(stype, Rm, imm5, C_in) else: // shift by register (op2[7] must be 0) amount = Reg(op2[11:8])[7:0] // only low byte used return ShiftReg(stype, Rm, amount, C_in) // ─── Shift by immediate ──────────────────────────────────────────────── function ShiftImm(stype, val, imm5, C_in): switch stype: 00: // LSL if imm5==0: return (val, C_in) // no shift return (val << imm5, val[32-imm5]) 01: // LSR (imm5=0 means #32) n = (imm5==0) ? 32 : imm5 return (val >>u n, val[n-1]) 10: // ASR (imm5=0 means #32) n = (imm5==0) ? 32 : imm5 return (val >>s n, val[n-1]) 11: // ROR (imm5=0 → RRX) if imm5==0: return ({C_in, val[31:1]}, val[0]) // RRX return (ROR32(val, imm5), val[imm5-1]) // ─── Shift by register ───────────────────────────────────────────────── function ShiftReg(stype, val, amount, C_in): // amount = Rs[7:0] if amount == 0: return (val, C_in) // no shift, C unchanged switch stype: 00: return (amount>=32) ? (0,0) : (val<<amount, val[32-amount]) 01: return (amount>=32) ? (0,0) : (val>>uamount, val[amount-1]) 10: return (amount>=32) ? (sign(val),val[31]) : (val>>samount, val[amount-1]) 11: n=amount&0x1F; return (n==0) ? (val,val[31]) : (ROR32(val,n), val[n-1]) // ─── Execute Data Processing instruction ─────────────────────────────── function ExecuteDP(cond, opcode, S, Rn, Rd, I, op2): if not ConditionPassed(cond): return // instruction skipped (Op2, C_shift) = DecodeOperand2(I, op2, CPSR.C) Rn_val = Reg(Rn) // R15 reads as PC+8 (result, carry, overflow) = ALU(opcode, Rn_val, Op2, CPSR.C) if opcode not in {TST, TEQ, CMP, CMN}: // write-back result if Rd == 15: if S==1: CPSR = SPSR // exception return PC = result else: Reg(Rd) = result if S==1 and Rd != 15: // update flags CPSR.N = result[31] CPSR.Z = (result == 0) CPSR.C = isLogical(opcode) ? C_shift : carry CPSR.V = isLogical(opcode) ? CPSR.V : overflow // isLogical = {AND, EOR, ORR, BIC, MOV, MVN, TST, TEQ}

▪ Critical Compiler / Assembler Rules
#RuleDetails
1 Immediate encoding Before emitting an immediate, verify: ∃ rot ∈ {0..15} such that ROR(val, rot×2) ≤ 255. If no match → error or split into two instructions (e.g. MOV + ORR, or MOVW/MOVT on ARMv6T2+).
2 Test-ops S-bit TST / TEQ / CMP / CMN: S is implicitly 1 — always set in the encoding regardless of the assembly syntax. Rd field [15:12] must be 0b0000.
3 MOV / MVN Rn field Rn [19:16] must be 0b0000. Hardware ignores it, but a non-zero value produces a non-canonical encoding that may confuse disassemblers.
4 RRX encoding RRX is encoded as ROR with imm5=0: shift_type=0b11, imm5=0b00000, I=0, bit[4]=0. There is no shift-by-register form of RRX.
5 LSR / ASR #32 A shift of 32 is encoded with imm5=0: LSR#32 → stype=01, imm5=00000; ASR#32 → stype=10, imm5=00000. The value 32 does not fit in 5 bits.
6 Shift-by-register constraints Rm ≠ R15, Rs ≠ R15, Rd ≠ R15, Rn ≠ R15. Bit[7] must be 0 (otherwise decoded as Multiply). Only Rs[7:0] contributes to the shift amount.
7 PC as operand Reading Rn=R15: value = instruction_address + 8. Writing Rd=R15: acts as a branch (BX-like). With S=1 and Rd=R15: CPSR ← SPSR (exception return).
8 Cond = 1111 (NV) ARMv4: NV treated as NOP. ARMv5+: enters the unconditional instruction space (PLD, BLX(1), etc.). Do not use 0b1111 for ordinary conditional instructions.
9 Instruction class disambiguation Bits [27:26]=0b00 select Data Processing. Within that space, if [25]=0 and [7:4]=0b1001 the encoding is Multiply / Swap, not DP. If [25]=0 and [7:4] ∈ {0b1011, 0b11x1} it is Extra Load/Store. Decoders must check these patterns before falling through to DP.
10 C-flag for logical ops (S=1) For AND, EOR, ORR, BIC, MOV, MVN, TST, TEQ with S=1: CPSR.C = C_shift (carry-out of the barrel shifter). CPSR.V is left unchanged. Arithmetic ops (ADD, SUB, etc.) use the ALU carry/overflow instead.
▪ Decode Priority Tree — ARMv7-A/R conditional instruction space
[31:28] ≠ 1111 → conditional instruction (evaluate Cond, skip if false) [31:28] == 1111 → unconditional space (ARMv5+: Hints, PLD, BLX(1), SETEND, etc.) Conditional path — bits [27:26]: 00 → Data Processing / Miscellaneous 01 → Load / Store (word, byte) 10 → Branch (B, BL) / Block transfer (LDM, STM) 11 → Coprocessor / SVC Data Processing / Miscellaneous — bit [25]: 1 → DP Immediate (I=1) 0 → Register form — check [7:4] first: [7:4] == 1001 → Multiply / Swap [7:4] == 1011 or 11x1 → Extra Load/Store (halfword, signed byte) [24:23]==10 and [20]==0 and [7]==0 → Miscellaneous (MRS, MSR, BX, CLZ, …) otherwise → DP Register [4] == 0 → shift-by-immediate [4] == 1, [7] == 0 → shift-by-register
